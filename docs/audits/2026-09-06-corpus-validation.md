# 0.7.1 真实语料验证

本轮使用 46 份新的本机文件进行测试并生成 0.7.1 生产构建。44 份受支持的输入均完成转换；另外一份加密 PDF 正确等待密码，一份旧版 DOC 正确提示格式不支持。转换完成只表示流程及产物可用，复杂矢量图表、扫描图片和 EMF 等质量边界仍需核对。

## 抽样与范围

- 只读盘点 7,001 个文件，其中 PDF 4,884 份、DOCX 337 份。
- 跨月份抽查 881 份 PDF，完整读取 337 份 DOCX、49 份 Markdown、6 份图片和 46 份旧版 DOC 的基础信息，共检查 1,319 个候选。
- 固定随机种子并结合大小、页数、文字层、旋转、图片、表格、页码域和合并单元格选取 46 个不重复文件，覆盖 15 个月份；均未使用上一轮样本路径。
- 包含约 420 MiB、614 页的 PDF，84 张表格的 Word，73,781 字符的 Word，以及超过 216 万字符的 Markdown。
- 23 份 PDF 按全文转换，共 383 页；另 3 份 PDF 按首、中、末页抽取，共导出 7 页图片。加密 PDF 未尝试猜测密码。
- 所有源文件的 SHA-256 在测试前后相同。私有路径、文件名、内容、截图、清单和产物仅保存在本机忽略目录。

## 产物及浏览器核对

- 16 份 Word/Markdown 输出 PDF 共 2,643 页，逐页重新打开和渲染，未发现文字坐标超出纸张边界；这不是逐页像素级保真的承诺。
- 所有 DOCX/ZIP 均通过包与 XML 结构检查；13 份 DOCX 经本机 Word 转为 PDF 后共 274 页，全部可渲染。
- 用 Poppler 额外检查 Word 表格、EMF 占位、长文档前后段、中文代码间距和宽表格；抽查了 PDF → Word 的中英文段落、有线表格、旋转页和扫描长图。
- 合成图片 PDF 的页序、90° 旋转和 A4 边距正确，两张嵌入图片与源图解码像素一致。
- 四种界面语言在 1440、390、320 px 宽度下均无横向溢出，键盘焦点可见。
- 文档联网、资源等待取消和后续转换脚本通过；私有语料转换期间未记录到文档触发的外部请求或页面异常。
- `npm run check` 通过：240 项测试、TypeScript 检查、格式检查及生产构建。新增浏览器回归另行实际执行，未把它计入 Vitest 数量。

## 保留的质量边界

- 一份原生 PDF 的复杂矢量图表在可编辑 Word 中不能完整重建；图中的文字或嵌入位图可保留，曲线和几何形状可能缺失。需要完整外观时使用 PDF → 图片。README 已补充这一点。
- EMF/WMF 仍需在原 Word 中替换为 PNG/JPEG。占位和提示使缺失可见，不能代替解码原图。
- 扫描长图保留为图片片段，图内文字不可编辑；OCR 内容与复杂排版仍需对照原文。
- Word 与原 PDF 页数可能不同；分页、字体替换、合并单元格和图形位置不保证像素一致。Markdown 中的 LaTeX 公式仍按源文本输出。
- 本轮覆盖 Chromium 和本机 Microsoft Word，没有扩大到 Firefox、Safari 或全部 Office 实现。
