# 导航与设置精简（0.8.1）

起因：三组导航在桌面上排成「两组 + 一组」，第三组单独掉到第二行；图片工具一次露出六项设置，用户容易迷糊。

## 改法

1. 导航：桌面三组并排、组名在上、每组三个等宽；平板和手机每组一行、组名在左（手机去掉图标）。
   计数徽标挂在右上角，出现时不挤动导航。
2. 图片工具每个只露出一项核心设置，「更多选项」里各一项：
   压缩是画质（高清 / 标准 / 小体积 / 指定大小）+ 输出格式；转换是目标格式（选 JPG 时带底色）+ 画质；
   改尺寸是尺寸方式 + DPI。透明背景不再单独设置：PNG / WebP 保留，JPG 填底色。
   其余参数按工具固定，旧版本存下的设置不会悄悄生效。
3. 图片拖进来就自动处理，改设置自动重做；保留「停止 / 继续」。没有图片时不显示操作栏。
4. 图片转 PDF 只露出「页面」，纸张固定时才出现「方向」，页边距和图片质量收进「更多选项」。
5. 细节：图片工具说明缩短到一行，上传区标题均衡换行，触屏不显示 Ctrl+V 提示。

## 验证

桌面 1440×900、平板 820、手机 390，浅色 / 深色，中英日界面逐页截图检查；
处理中停止 / 继续、改设置、追加图片、清空等流程在开发站实测；完整门禁与浏览器回归脚本。
