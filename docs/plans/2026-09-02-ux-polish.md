# Local PDF 0.5.0 UX Polish Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 完成一轮跨六个工具的体验、交互、排版、样式与性能优化，并发布 0.5.0。

**Architecture:** 不改变转换核心和现有 React 架构；活动状态由顶层根据现有队列派生，图片工具以轻量回调上报。上传语义、页面 head 和编辑器状态在各自现有组件内做小范围修正。

**Tech Stack:** React 19、TypeScript、Vite、Vitest、CSS、Playwright CLI、Cloudflare Wrangler。
