# 输出模式与质量分级

PDF 描述"在坐标处画什么"，Word 描述"段落、表格、样式的流式排版"。
不可能同时承诺"完全可编辑"和"像素级一致"，所以模式必须显式给用户选。

## 可编辑模式（默认）

识别段落、标题、列表、表格、图片，生成结构化 DOCX。

优点：文字能正常编辑，表格是真表格，Word 能自动重排，文件小。
代价：字体替换会让换行位置变化；宣传页、海报这类自由版式还原不了。

## 纯文本模式

只保留阅读顺序和文字，忽略表格结构、图片、复杂几何。

用途：版面太复杂、可编辑模式结果不理想时的兜底。至少保证内容不丢。

## 高保真模式（未实现）

用 Word 的浮动文本框/浮动图片按原坐标摆放。视觉接近，但编辑体验差，
且不同 Word 实现之间兼容性更复杂。见 ROADMAP。

## 质量指标

评价一次转换不能只看"DOCX 能不能打开"。有意义的指标：

### 文本
- 字符召回率 / 归一化字符准确率 / 多余字符率
- 阅读顺序准确率
- **中文错误空格率**、**英文缺失空格率**（中英混排最容易出问题的地方）
- 段落边界 F1

### 表格
- 行列数正确率、单元格检测 F1、合并单元格正确率
- 文本到单元格映射正确率
- **错误表格识别率**（无框线表格默认关闭就是为了压这个指标）

### 图片
- 数量、页面归属、顺序、裁剪区域重叠率

### 兼容性
生成的 DOCX 需要在 Microsoft Word、LibreOffice、OnlyOffice 里都能正常打开。
CI 里可以用 LibreOffice 把 DOCX 再渲染成 PDF，与原 PDF 做视觉差异比较——
注意这只适合发现"图片丢失、整页空白、严重错位"，不能当唯一指标，
因为可编辑模式本来就允许合理重排。

## 置信度

每页输出 `confidence`（0~1），来源：

- 分栏切分时那条竖向空隙有多宽（越接近阈值越不确定）
- 栏数超过 3 时下调
- 表格框线完整度（有框线的格边数 / 总格边数）

**低置信度不应该被隐藏。** 转换报告里逐页展示，让用户知道哪几页值得核对，
这比无限堆启发式规则更有效。
